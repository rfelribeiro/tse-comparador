# Comparador de Eleições Presidenciais: 2022 (2º turno) × 2026 (1º turno)

Aplicação estática que compara os resultados oficiais do Tribunal Superior Eleitoral (TSE) das eleições presidenciais de 2022 (segundo turno) e de 2026 (primeiro turno), com visualizações por estado e município.

## Fontes de dados

_A definir: descrever aqui as fontes oficiais (TSE) de cada eleição, os arquivos baixados e a data de coleta._

## Como rodar

```bash
npm install
npm run data
npm run dev
```
